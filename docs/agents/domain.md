# Domain Docs

## Before exploring

- Read root `CONTEXT.md`, if present.
- Read root `CONTEXT-MAP.md`, if present, and relevant referenced contexts.
- Read relevant `docs/adr/` records.
- Proceed silently when these files do not exist.

## Layout

This is a single-context repository. Domain glossary lives in root `CONTEXT.md`; architecture decisions live in `docs/adr/`.

Use glossary terms in issues, designs, and tests. Surface any conflict with an existing ADR.
